# Kingsley Aremu's Portfolio — v1 (2025)

## Overview

v1 of Kingsley Aremu's portfolio, originally shipped in 2025. A React (Native) Web and Mobile App Developer showcase covering experience, skills, education, and certifications.

This site stays live as part of the portfolio's version history — every version keeps its own URL:

- **v1 (this repo):** [kingsleyaremu-v1.vercel.app](https://kingsleyaremu-v1.vercel.app)
- **Current version:** [kingsleyaremu.vercel.app](https://kingsleyaremu.vercel.app)

## Features

- Single-page layout with smooth-scroll section navigation
- Light/dark theme toggle with system detection
- Responsive design using Tailwind CSS
- SEO and social meta tags (Open Graph, Twitter)
- Works without JavaScript (noscript fallbacks, native form post)
- Built with Next.js and TypeScript

## Stack

- [Next.js](https://nextjs.org/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Vercel](https://vercel.com/) (deployment)
